# Plan — 260803-f01: dataset documentation page

## Goal

Publish `docs/dataset.md` — a full breakdown of the basketball dataset (image
counts, per-class annotation counts per split, class taxonomy and how it
collapses, provenance, licence) whose real payload is two caveats a reader
cannot infer from the numbers alone:

1. **These are consecutive video frames, not independent images.** 654 images
   come from 21 clips; the 94-image test split is **3 clips**. Effective sample
   size tracks the clip count, not the image count, so a naive per-image CI is
   far too narrow.
2. **No clip-level leakage, but all splits share the same 3 games.** Clean at
   clip granularity, correlated at game level. Both halves stated.

Plus the class imbalance that explains why `ball`/`rim` AP is noisy in the
reports.

## Design constraint (the thing that shapes everything)

Repo core value: *every number the blog posts publish must be reproducible from
this repo*, and **no report number is ever typed by hand**. Tables are emitted
by `scripts/generate_report.py` between `<!-- TABLE:name START/END -->` markers;
`--check` is the CI drift gate.

The dataset lives **outside the repo** and CI has no copy of it. So this page
follows the VLM precedent exactly:

```
raw dataset  --(local, GT-touching)-->  committed derived JSON  --(GT-free)-->  tables
             scripts/write_dataset_stats.py   results/dataset/    report/{loaders,tables}
                                              dataset_stats.json  generate_report.py --check
```

`write_dataset_stats.py` is the *sole* place that reads the dataset (mirroring
`write_vlm_metrics.py`). The generator and its drift gate read only the
committed JSON, so `--check` runs where the dataset is absent.

### The wrinkle, and how it is resolved

Nothing in CI can prove the committed `dataset_stats.json` still matches the
real dataset — the same gap the VLM metrics file already has and the repo
already accepts. Rather than leave it implicit, `write_dataset_stats.py` gets a
`--check` mode: run locally where the dataset exists, it recomputes and diffs
against the committed file. That makes the gap a *runnable local gate* instead
of an unstated assumption, and the page says so in prose. No new CI dependency
on the dataset.

## Tasks

### T1 — promote clip identity into `src/` (one definition, not two)

`scripts/run_clustered_bootstrap.py` already owns `_CLIP_RE` / `clip_key`. The
stats script needs the same notion of "which clip is this frame from". Two
copies of that regex is a drift source in exactly the dimension this page is
about, so promote it:

- new `src/object_detection_eval/data/clips.py` (stdlib-only, torch-free):
  `clip_key()` (behaviour-identical, so `bootstrap_clustered_7models.json` keys
  are unchanged), plus `game_id()` for the game-level correlation caveat.
- `run_clustered_bootstrap.py` imports it instead of redefining it.
- tests: `tests/data/test_clips.py`.

### T2 — `scripts/write_dataset_stats.py` + committed JSON

Reads `{train,valid,test}/_annotations.coco.json`; emits
`benchmarks/basketball/results/dataset/dataset_stats.json`:
per-split image/clip/annotation counts, per-class counts at raw10 **and**
merged5, image geometry, the full clip inventory, and pairwise split overlap
(shared clips + shared games). `--check` recomputes and diffs. loguru only.

### T3 — loader + renderers

- `report/loaders.py`: strict frozen `DatasetStats` models + `load_dataset_stats`.
- `report/tables.py`: split table, image-geometry line, raw10 + merged5 class
  tables, taxonomy merge table, taxonomy alias table, clip inventory, derived
  clip-structure paragraph, derived split-overlap table + verdict.
  Every verdict/ratio DERIVED, never typed (the `ci_table` precedent).
- fixture + golden tests binding a rendered cell to the fixture value.

### T4 — the page and the site wiring

- `docs/dataset.md`: prose + 9 marker slots; links to
  `metrics/bootstrap.py` and `run_clustered_bootstrap.py` for caveat 1.
- `generate_report.py`: `docs_dir` param, `--docs-dir` flag, `dataset` spec.
- `scripts/stage_docs.py` + `mkdocs.yml` nav; cross-links from `README.md` and
  `docs/methodology.md`.

**Not touching** `benchmarks/basketball/reports/*.md` — PR #15 is open against
the VLM report and this task must not collide with it.
