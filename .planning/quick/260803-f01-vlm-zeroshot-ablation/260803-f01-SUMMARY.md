# Summary — 260803-f01: maximise zero-shot VLM performance by disciplined ablation

## What this was

PR #15 equalised the *prompt* across the five open-weights zero-shot VLMs.
Everything else about how they run — NMS IoU, box threshold, singleton `top_k`,
checkpoint, input resolution — was still whatever the first commit picked, and
some of it was not even equal across models. This task swept all of it, one
element at a time on the 96-image val split, keeping a change only when it
helped and recording it either way.

**~170 arms measured. Nothing was chosen on `test`.**

## The rule, fixed before the results

Written into PLAN.md at 03:10 UTC while tiling, the Florence-2 NMS element, the
per-class vocabulary and the checkpoint re-search were all still running, so it
cannot have been shaped around what it decides:

1. Adopt only if the best arm beats the model's baseline by **≥ 0.002 mAP@50:95**.
   96 val images under COCO's 101-point interpolation do not resolve a
   thousandth of a point; adopting a +0.0005 win is fitting the val split, which
   is the same mistake as fitting test one step removed.
2. **Argmax** within an adopted element, ties to the manifest's first value. No
   hand-picking a sensible-looking value near the top — that is where quiet
   fitting re-enters.
3. **Stacking is measured, not assumed.** Single-element deltas are taken
   against a baseline that stops existing the moment another element is
   accepted.
4. A **winning checkpoint re-runs the vocabulary search** against its own weights.

## What was found

### Tiling is the biggest lever, and it splits the roster

Overlapping 2x2 tiles plus the full frame, merged by the existing per-class NMS:

| Model | baseline | 2x2 tiles | Δ | where it came from |
| --- | --- | --- | --- | --- |
| OWLv2 | 0.2400 | 0.2831 | **+0.0431** | — |
| Grounding-DINO | 0.2443 | 0.2776 | **+0.0332** | `referee` 0.239 → 0.445 |
| OmDet-Turbo | 0.1807 | 0.2066 | **+0.0259** | `number` 0.042 → 0.149, `ball` 0.130 → 0.208 |
| Florence-2 | 0.1246 | 0.1350 | +0.0105 | `number` 0.058 → 0.218 |
| YOLO-World | 0.1318 | 0.0790 | **−0.0529** | `player` 0.777 → 0.450 |

The prediction written into `tiled.py`'s docstring *before* measuring — that
tiling would help `ball` and `number` but **not** `rim`, because the prompt
search had put `rim` at 0.000 in essentially all thirty model-by-prompt cells,
making it a grounding failure rather than a resolution one — held. `rim` stayed
0.000 in every tiled arm.

YOLO-World is the one model with a native resolution knob, and raising `imgsz`
to 1280 bought it +0.0134. Tiling and `imgsz` are the same lever for it, and
tiling is the worse implementation.

### The combination arms earned their place immediately

OWLv2 adopted NMS IoU 1.0 (no suppression) because that won on the untiled
model. Stacked with tiling it scored **0.2424 against 0.2831 for tiling alone** —
worse than either change by itself. Tiling runs the model on five overlapping
crops, so the pipeline manufactures the very duplicates "suppress nothing"
was chosen to keep. Re-sweeping NMS inside the tiled regime fixed it, at zero
forward-pass cost.

This is the clearest evidence in the exercise that single-element deltas cannot
be added: two changes acting on the same detections do not compose, and here
they actively fought.

### Negative results, kept

- **`box_threshold` is inert.** Flat for every model until it starts cutting
  real detections. Predicted, and confirmed rather than assumed.
- **Every checkpoint variant lost except Florence-2's.** OWLv2 base −0.060,
  OWLv2 finetuned −0.069, Grounding-DINO tiny −0.032, YOLO-World l/m/s all
  worse. The published checkpoints were already the best of their families.
- **Adding NMS to Florence-2 does exactly +0.0000.** It assigns every detection
  confidence 1.0, so suppression has no ranking to work with.
- **The Florence-2 vocabulary re-search returned the incumbent.** The
  equal-effort rule reporting a null result rather than a win.
- **`singleton_top_k` moved nothing** beyond the noise floor once re-confirmed
  under the new NMS and threshold settings.
- **OmDet-Turbo's NMS is a no-op above 0.5**, because its HF processor runs a
  second, hardwired `batched_nms` first — which no manifest had ever mentioned.

## Defects found in the process

- **OmDet-Turbo was suppressed twice.** The HF processor's own `nms_threshold`
  was never passed, sat at the library default, and the manifest documented the
  *outer* NMS as though that were the model's setting.
- **Florence-2's NMS element was unshippable** — the ablation could apply
  suppression offline while the inferencer could not, so a winning arm could
  never have been reproduced on test.
- **YOLO-World's NMS cannot be replayed offline** at all: ultralytics suppresses
  in letterboxed pixel space, and normalising divides x and y by different
  factors on a non-square image. Those arms run live rather than approximated.
- **A cache filename overflowed the 255-byte limit** and killed a full CUDA
  sweep 111 arms in. Fixed, and one bad signature no longer aborts the run.

## Method notes

- **MPS vs CUDA was measured, not assumed.** 86 arms scored on both: median gap
  0.000000, max 0.000733, zero arms disagreeing by more than the adoption noise
  floor. Committed as `results/vlm/ablation/substrate_check.json`.
- **The raw-detection cache** runs each configuration once un-suppressed at a
  0.001 floor and replays the whole threshold/NMS/top-k grid over it. Exact for
  greedy NMS, and `--verify` checks cached against live scoring rather than
  asking anyone to take it on faith (measured gap: 0.00e+00).

## GPU discipline

Three rented boxes. Two were destroyed by their own dead-man's switch during
long gaps in the controlling session — working as intended, and the reason
there is no orphan. The first watchdog's 90-minute silence window was wrong in
both directions: it killed healthy jobs, while no upper bound at all is how this
project previously orphaned an instance for 41 hours. Final form is a long
silence window plus a hard lifetime cap, so the cap does the orphan-prevention
and the window stops fighting the work.

One avoidable loss: the OSError crash left a box idle for ~7.5 hours (~$0.97)
because the crash detector had a `pgrep -f` bug that matched its own SSH command
and could never fire.
