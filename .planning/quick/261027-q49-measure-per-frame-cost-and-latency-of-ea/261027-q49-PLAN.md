<objective>
Build everything needed to measure what each zero-shot API pipeline costs per frame
(USD and seconds), so the blog can say what a team pays for each accuracy level. This
plan covers ONLY code, configs, tests and docs that make ZERO paid API calls. The paid
projection, the two logged reruns, and final report generation are an orchestrator
follow-up (see the section at the end), because spending money needs a human-gated
budget check.

Purpose: the core value of this repo is that every published number is reproducible
from it. Cost numbers are no exception: they must come from committed per-call usage
logs, a committed price table with sources, and a generator, never from hand arithmetic.

Output:
- Step 1: permanent per-call JSONL usage logging in every API inferencer (Astra, Sol,
  Opus, Gemini, DINO-X, T-Rex), with offline tests.
- Step 2 (reduced by user decision 2026-10-27, relayed by the coordinator): OpenAI and
  Anthropic admin billing readers are NOT built and there is NO billing-comparison
  column or >25% flag. Step 2 is exactly two written docs: Google Cloud Billing export
  instructions and a DINO-X console checklist.
- Step 3 tooling: seeded, clip-stratified 20-frame val list (committed), a rerun driver
  (one pipeline x one run, caches bypassed, published --workers, --max-frames 3), and a
  projection gate against the 40 USD cap.
- Step 4 tooling: price config, published-accuracy config, aggregator -> JSON -> COST.md
  -> PNG, with tests on synthetic usage logs written through the real Step 1 writer.

Task order note: the orchestrator suggested T1 logging / T2 Step 2 / T3 Steps 3+4. After
Step 2 shrank to two docs, the Step 4 compute/report tooling moves into Task 2 (it is
what Task 3's projection gate calls), and Task 3 is the Step 3 rerun tooling. All three
remain zero-cost.
