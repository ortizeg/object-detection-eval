<objective>
Build `scripts/run_latency.py`, the LAT-01 uniform end-to-end latency harness, plus its committed manifest and offline tests. The harness times each of the 7 medium detectors over the full `preprocess → session.run → postprocess/NMS → to-boxes` path by calling the detector's own `predict()` — the identical `ONNXInferencer` subclasses `run_benchmark.py` scores accuracy through — with a warmup phase and steady-state median/p90 percentiles, batch 1, at a deployment-realistic `conf=0.25`. It is a reader-reproducible port of the source repo's ad-hoc, never-committed `.deploy_comparison/latency/time_models.py` onto this repo's Phase-2 inference stack. This plan also lands the LAT-04 band-check helpers (the §6 fp16 to-boxes band `[4.0, 7.1]` ms and the on-GPU NMS-delta band `[0.05, 0.2]` ms) that Plan 06-03's T4 gate consumes.

Purpose: this is the CPU-developable core of Phase 6 — the harness, manifest, and gate helpers are all written and unit-tested on this macOS/CPU machine with no GPU; only the *published* T4 number (Plan 06-03) needs the rented hardware. CI covers the offline manifest shape and the pure statistics/band helpers; the actual timing run is executor-run on the box at Plan 06-03's checkpoint, mirroring `run_benchmark.py`'s NOT-wired-into-pytest precedent. (LAT-01, LAT-04)
Output: `scripts/run_latency.py`, `benchmarks/basketball/conf/latency_640.yaml`, `tests/scripts/test_run_latency.py`.
</objective>
