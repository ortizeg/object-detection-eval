<objective>
Build the report generator: a torch-free `src/object_detection_eval/report/` package (typed
loaders per results-file shape, pure markdown-table renderers, marker-comment injection) plus a
thin `scripts/generate_report.py` CLI with `--check` (CI drift gate) and `--write` (regenerate)
modes. This is the machine that makes REPORT-01 real — every table in every Phase 7 report is
emitted here from a committed results file, and `--check` fails if a report ever drifts from its
data. All renderers for both reports (the 7-model accuracy comparison, CIs, per-class 5c/10c,
the latency section, the VLM summary + per-class failure tables) are built and tested here so the
Wave-2 report plans only author prose and run `--write`, with no shared-file edits back into the
generator.

Purpose: the generator is pure, hermetic, and torch-free — it only reads JSON and emits strings —
so it lives in the default `pixi run test` suite and its golden tests catch drift automatically.
It is developed against small synthetic fixtures (not the real 94-image committed data) to stay
fast and independent of results-file regeneration. (REPORT-01)
Output: the `report/` package, `scripts/generate_report.py`, and the `tests/report/` suite with
fixtures.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| committed results JSON → report loaders | untrusted-shape file parsed into typed models |
| generated table markdown → target .md marker region | machine-owned bytes replacing a bounded region of a human-authored doc |
| report .md on disk → --check verdict | drift between committed prose-tables and committed data gates CI |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-04 | Tampering | a malformed/hand-edited results JSON silently rendering a wrong/blank cell | high | mitigate | Frozen extra=forbid pydantic loaders (V5 input validation) fail loudly at load time on an unexpected or missing field, matching ModelCard's convention |
| T-07-05 | Tampering / DoS-of-doc | marker regex matching zero or multiple sections and corrupting prose | high | mitigate | inject_table asserts exactly one marker-pair match and raises ValueError otherwise — never silently no-ops or spans an unintended region |
| T-07-06 | Tampering (of trust) | a hand-edited table cell drifting from the data behind it | high | mitigate | --check render-and-compare exits nonzero on drift; a golden cell test binds a rendered value to the results-file value |
| T-07-07 | Tampering | the torch-free boundary widening (report/ importing inference/vlm/* or ONNX runtime) | medium | mitigate | load_vlm_metrics reads pre-computed prediction JSON through supervision/compute_metrics only; the whole suite runs in the default torch-free CI selection, which fails on an accidental torch import |
</threat_model>
