<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote weight host (HF Hub / GCS / arbitrary URL) → local cache filesystem | Untrusted bytes fetched over the network are written to the reader's disk |
| card-declared URL → fetcher dispatch | A card's `weights.url` selects a scheme handler (file:// reads local disk, http(s):// opens a socket) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Tampering | download_weights stream/verify | high | mitigate | Stream to `.part`, hash on arrival, promote only on SHA-256 match; ChecksumMismatchError unlinks the `.part` in a `finally`/except so tampered bytes never reach the cache (REG-03) |
| T-03-05 | Elevation | redistributable guard | high | mitigate | The AGPL guard raises WeightsNotRedistributableError before any I/O, so non-redistributable weights can never be fetched or cached (REG-04) |
| T-03-06 | Information Disclosure | fetch_http follow_redirects / SSRF | medium | mitigate | SUPPORTED_SCHEMES allowlist (http/https/file) is the only reachable dispatch; the SHA-256 gate means a redirected/substituted response that does not match the card digest is rejected. Residual SSRF on an operator-run dev fetch accepted |
| T-03-07 | Tampering | cache path from weights.filename | medium | mitigate | `filename` is `Path(urlsplit(url).path).name` (directory components stripped) and `cached_path` nests under `card.name` (pattern `^[a-z0-9][a-z0-9._-]*$`, no slashes) — path traversal out of the cache dir is not reachable |
| T-03-08 | Denial of Service | unbounded download size | low | accept | No content-length cap; download is operator-initiated on a dev machine against a known card. Accepted for v1 |
</threat_model>
