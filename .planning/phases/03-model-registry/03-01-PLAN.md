<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted YAML card file → ModelCard parser | A card (hand-authored, copied from the web, or contributed) crosses into typed, trusted config |
| card `weights.url` string → downstream fetch (Plan 02) | A URL declared in a card is a target the download tier will act on |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | ModelCard.from_yaml | medium | mitigate | `extra="forbid"` + `frozen=True` + typed validators; from_yaml raises CardValidationError on any malformed card (unknown key, wrong type, bad sha256 pattern) |
| T-03-02 | Elevation | redistribution model_validator | high | mitigate | The §11 AGPL contract as schema: redistributable:false MUST omit weights and MUST carry reproduction — a contributor cannot even load an AGPL card that declares a weights URL |
| T-03-03 | Information Disclosure | WeightsSpec url scheme validator | low | accept | Card only validates the scheme is in SUPPORTED_SCHEMES; a `file://` url could name a local path, but no file is READ at schema time (read is gated by the SHA-256 verify in Plan 02). Residual risk accepted for schema tier |
</threat_model>
