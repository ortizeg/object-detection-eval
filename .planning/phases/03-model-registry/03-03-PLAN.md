## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local ONNX + operator HF credentials → public HF Hub | Publishing crosses from private local artifacts to a world-readable model repo |
| card `redistributable` flag → upload decision | The flag alone gates whether a binary may ever leave the machine |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-09 | Elevation | publish_weights redistributable filter | critical | mitigate | `if not card.redistributable: continue` skips AGPL cards by construction; the mocked test asserts the uploader is NEVER called for a redistributable:false card, so YOLO26 weights cannot be published (the §11 legal contract) |
| T-03-10 | Information Disclosure | HF credential handling | high | mitigate | HF token read from the environment by HfApi, never passed on the CLI, never logged; the injectable uploader means tests run with no token at all |
| T-03-11 | Tampering | card digest vs uploaded bytes | medium | mitigate | publish recomputes sha256 from the actual local ONNX via download.sha256_file and refreshes the card, so a card's recorded digest always equals the bytes uploaded (no stale/placeholder digest survives a publish) |
| T-03-SC | Tampering | huggingface-hub dependency (supply chain) | low | accept | No new package install task — huggingface-hub is already pinned in the pixi dev feature and lockfile; import is lazy and confined to the publish script (never in the torch-free core import graph). Legitimacy: established, widely-used Hugging Face package |
