<objective>
Port the scoring core as public, typed, tested functions independent of any task object: `compute_metrics()` (mAP + per-class AP@50 via `supervision`, CORE-02), the F1 threshold sweep (`compute_prf1_at_threshold`/`find_best_threshold`, CORE-03), and `compute_pr_curve` (CORE-03). PR-curve *plotting* (`_plot_pr_curves`, matplotlib) is explicitly DEFERRED to Phase 7 and is NOT ported here.

Purpose: These promote the private `_compute_metrics`/`_compute_prf1_at_threshold`/`_find_best_threshold`/`_compute_pr_curve` symbols into a stable public API and remove the reach into `supervision`'s internal `iou_and_nms` module path.
Output: `metrics/` package (three modules) + tests.
</objective>

<authoritative_requirement>CORE-02 is co-claimed with 02-04 (whose supervision version-pin re-validates the same `compute_metrics`). **This plan (02-03) is authoritative for CORE-02's pass/fail at phase verification** — it builds and unit-tests `compute_metrics` itself; 02-04 only measures its numeric stability across supervision versions.</authoritative_requirement>
