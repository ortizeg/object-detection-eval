<objective>
Build the inference foundation: the `BaseInferencer` ABC (CORE-07 seed), the generic `ONNXInferencer` (the RF-DETR ImageNet-style square-resize path), and — the Rule-of-Three payoff — ONE parameterized `Letterbox` preprocessor plus a single explicit de-transform function that together reproduce all five hand-rolled preprocessing variants from model-card-style config (CORE-06). The de-transform threads an explicit `LetterboxTransform` value object rather than mutating hidden postprocessor state (fixing the research Pattern-2 landmine).

Purpose: CORE-06 requires one parameterized letterbox + one tested de-transform; getting the numeric parameters exactly right (pad 114, top-left vs centered, int() vs round(), BGR/RGB, none/div255/mean-std, antialias) is what the Phase-4 byte-for-byte reproduction gate checks.
Output: `inference/{base,onnx,preprocess}.py` + a parametrized preprocess test over the 5 variants.
</objective>
